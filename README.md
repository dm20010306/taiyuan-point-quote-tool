# 智能图纸点位与报价工具

当前稳定版本：V3.3（用户已验收并批准）。当前 GitHub 初始化版本：V3.4-dev，尚未作为稳定版验收。报价系统支持网页编辑、预览及 PDF、Excel、PPTX 导出。详细结构、产品导入字段和迁移说明见 [docs/报价模块V2.md](docs/报价模块V2.md)。

GitHub 仓库和下载包不包含业务 `data/`。正式版本会提供名为 `态元智控工具V<版本号>` 的下载压缩包，解压后目录也带有相同中文名称和版本号；请从 GitHub 仓库的 Releases 下载该版本包。GitHub 的 Code → Download ZIP 是源码归档，默认解压目录名由仓库和分支决定。

Mac/Windows 从本机工具文件夹启动时，如果同级已有 `data/`，程序会读写它，适合手动复制整个文件夹在电脑间转移数据；没有 `data/` 时，继续使用电脑本机数据目录：Mac 为 `~/Library/Application Support/TaiyuanPointQuote/data/`，Windows 为 `%LOCALAPPDATA%\TaiyuanPointQuote\data\`。Mac 从 NAS 启动始终使用这台 Mac 的本机数据目录，不读写 NAS 上的 `data/`。程序不会自动同步；不要在多台电脑同时打开同一份便携 `data/`。GitHub 更新包不带业务数据，更新便携数据时需将整个 `data/` 复制到新版本工具文件夹。

## 启动

只保留两个用户启动入口：

- **Mac**：双击工具根目录的 `start-mac.command`，也可在终端执行完整脚本路径；Finder 与终端启动均按脚本所在目录解析，支持 NAS 挂载、中文和空格路径。
- **Windows**：从 GitHub Releases 下载版本包，解压到本机固定磁盘，再双击 `start-windows.bat`。工具文件夹有 `data/` 时使用便携数据；没有时使用当前 Windows 用户的本机数据目录。Windows 不支持从网络盘运行。

浏览器使用本机地址 <http://127.0.0.1:5173>。下载新版本时不要删除本机数据目录。本工具不提供 LAN/手机远程启动方式。
更新代码后，先关闭上一次启动工具的 Terminal 窗口，再重新运行入口；已有服务可能被复用，旧后端不会自动热重载。

`macos-launcher/`、`run-windows-api.bat`、`run-windows-web.bat` 和 Windows 校验/等待脚本是内部启动组件，不需要用户单独运行。Windows 启动错误日志保存在 `%TEMP%\PointQuote-startup.log`。

## 使用顺序

1. 项目页创建项目，填写名称、客户与地址。项目卡片右上角铅笔按钮可修改项目名称、客户、地址和状态；垃圾桶按钮可删除项目。删除会一并清理该项目的图纸、点位和报价，但不会删除知识库产品。
2. 图纸页上方依次选择楼层、图纸、图层；当前只显示所选图层设备，切换图层不会移动旧点位。新点进入所选图层，图纸导出也只包含这一层。各自的新增、重命名、复制与删除操作在对应的「管理」菜单；图纸选择旁可上传 JPG、PNG 或 PDF，PDF 先填写页码。图纸和图层可以分别复制到其他楼层。
3. 用 Q/W/E/R/A/S/D/F/G/H/J 快捷键选择设备后连续布点；开关也直接布点，随后在点位详情中关联产品。Esc、右键或切换工具退出。网络点位分为吸顶 AP 和墙面 AP。窗帘通过拖拽绘制带方向箭头的线段，详情中调整线条粗细；调光和非智能区域通过拖拽绘制。非智能区域仅用于图纸表达，不关联产品、不计入点位数量和报价。
4. 选择点位，设置名称、房间、数量等；普通设备新建大小为 20，可用数字框和滑块调节。拖动点位；用拖动画布工具或按住 Space 平移，滚轮缩放。Shift 点击可多选，选择模式下在空白处拖动可框选。选中多个同类型点位可以批量配置同一产品。Ctrl/Cmd+C 复制，鼠标移到图纸目标位置后 Ctrl/Cmd+V 粘贴。图例项可以分别拖动，也可以按「移动全部图例」一起移动。
5. 产品库与知识库笔记统一按“所属系统”管理；“适用点位”单独选择智能开关、窗帘、传感器等点位类型。填写品牌、售价、可选进货价和图片后会生成 Obsidian 笔记，也可导入 CSV/XLSX。点位详情按适用点位、品牌和产品筛选。当前项目价格可单独修改。产品页支持全选、批量改所属系统、启用、停用和删除。
6. 报价页按设备柜体、中控、触控、遮阳、暖通、线材、可视对讲、网络、监控、背景音乐、灯控排序；空系统默认隐藏。编辑模式支持同一系统跨页拖动排序、替换产品（数量恢复为 1）及施工调试费设置。五项非零施工调试费显示在报价末尾，计入总额但不参与折扣或税额；旧报价自动以 0 元兼容。批量加入产品时每款使用标准价，添加后可分别修改数量、项目单价和备注。产品明细支持网页预览与 PDF 导出；Excel/PPTX 导出规则保持原样。

项目快照和产品笔记保存在本机数据目录，SQLite 用作运行索引；点位名称、房间、备注和单价输入框失焦后自动保存。右上角“已保存/保存失败”反映后端请求结果。

## 文件位置

| 路径 | 内容 |
| --- | --- |
| 本机工具文件夹 `data/` | 可选便携业务数据，用于手动转移，不上传 GitHub |
| Mac `~/Library/Application Support/TaiyuanPointQuote/data/` | Mac 本机数据回退位置；从 NAS 启动时使用此处 |
| Windows `%LOCALAPPDATA%\TaiyuanPointQuote\data\` | Windows 本机数据回退位置 |
| `<本机数据目录>/01_产品库/` | 按所属系统中文名分目录的产品 Markdown 笔记，包含品牌、售价和图片路径 |
| `<本机数据目录>/06_客户档案/智能图纸与报价/` | 本机项目、图纸点位和报价记录 |
| `<本机数据目录>/09_附件/` | 产品图片、品牌 Logo 和业务附件 |
| `<本机数据目录>/app.sqlite3` | 项目、图纸、点位、报价、费用及产品索引 |
| `<本机数据目录>/uploads/`、`exports/` | 上传图纸和本机生成的导出文件 |
| `assets/templates/` | 随工具程序发布的导入模板和报价母版 |
| `backend/` | FastAPI、SQLite 与导出逻辑 |
| `frontend/` | React/Vite 页面 |

浏览器下载导出文件时，服务端也会在当前选中的数据目录 `exports/` 留一份。备份或转移时复制整个 `data/`。不要把业务数据放进 GitHub；不同电脑没有后台同步，也不要同时打开同一份便携数据。

## 产品导入

CSV 用 UTF-8（带 BOM 也支持），或使用 XLSX。第一行列名如下：

`品牌,产品名称,分类,点位类型,所属系统,售价,进货价,产地,单位,参数,说明`

旧导入模板仍要求品牌、产品名称、分类、售价（旧表头“标准价格”仍可导入），但“分类”仅为兼容字段，不决定知识库目录或报价归类；应填写“所属系统”（当前 11 个系统 ID，无法确认时为 `uncategorized`）。点位类型用于关联图纸点位，可填写 switch、curtain、sensor、water、thermostat、light、lock、camera、ceiling_ap、wall_ap、av、system、other。旧 `network` 和“网络设备”继续读取为历史兼容类型，但新产品应明确选择吸顶 AP 或墙面 AP；两者的所属系统均为 `network`。非智能区域不是产品类型，不能导入产品。进货价和产地可以留空。价格以元为单位，保留两位小数。导入前会校验所有行；发现错误时整批不入库。产品图片在产品编辑页单独上传，PNG/WebP 透明通道保留，网页和报价用白底显示。模板只有表头，没有虚构产品。

每款产品一篇 `01_产品库/<所属系统中文名>/*.md` 笔记；缺少可靠系统归属的笔记进入 `01_产品库/未分类/`。YAML 的 `所属系统` 是目录和报价归类依据；旧 `分类` 字段仅保留兼容，不再决定目录。属性还含 `id`、`点位类型`、`状态`、`审核人`、售价（分）、可选进货价（分）、图片地址等；正文有可读的产品信息表与图片。网页只更新 `<!-- pointquote:start -->` 与 `<!-- pointquote:end -->` 间的内容，标记外由你在 Obsidian 写的功能、适用场景和关联内容会保留。网页停用产品会标记 `启用: false`。执行删除会直接删除产品数据库记录和对应 Markdown 笔记；为保证已生成的历史报价仍能显示原产品图片，图片附件及报价快照会保留。

## 已实现范围与限制

支持项目创建与删除、多图纸与 PDF 选页、图纸旋转、连续布点快捷键、窗帘线段、四角可编辑调光区域、点位拖动/复制/删除/编辑/锁定、缩放/平移/全屏、多选框选与批量处理、自动编号、正式点位图导出、统一产品分类、产品批量管理、产品快照、报价直接加项、明细备注、费用调整、分页 PDF 和 Excel 清单导出。帮助页包含简介、使用说明、版本记录和可附截图的问题反馈。直接加入报价的产品会保存当前产品与价格快照，并标记为“清单加项 / 不关联图纸”。金额在数据库中以“分”保存并计算，界面显示两位小数。报价不设置折扣金额。

第一版没有 AI 自动布点、KNX 模块或回路计算。PDF 图纸上传后按 144 DPI 渲染为编辑背景；如果原 PDF 为矢量 CAD 图，导出的点位图是高分辨率栅格 PDF，而非保留矢量图层。撤销/恢复在当前编辑会话有效，刷新后历史栈清空。当前系统按单机/单用户设计，没有账户与权限功能。

## 验证

前端可在 `frontend/` 运行 `npm run build`。后端业务测试须先将程序、静态资源和必需的空 `data/` 目录复制到独立临时工具目录，再在该目录设置 `POINT_QUOTE_ALLOW_APP_TESTS=1` 运行 `pytest backend -q`；直接在正式工具目录运行时，`test_app.py` 会跳过，避免写入真实业务数据。隔离测试覆盖 PNG/PDF 上传、点位编号与持久化、楼层/图层复制、图纸旋转、项目级联删除、历史价格快照、金额计算、产品图片、CSV 导入及导出。

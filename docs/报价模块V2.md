# 报价模块 V2

## 模块结构

项目中的报价现在是独立模块：

```text
项目
├── 图纸与点位
├── 产品配置
└── 报价 V2
    ├── 网页编辑
    ├── 正式预览
    ├── 报价版本
    └── PDF 导出
```

编辑、预览和 PDF 使用同一个 `QuotationDocument`。金额统一以“分”为单位计算，显示时才格式化为人民币。

## 11 个报价系统

| 顺序 | ID | 中文 | English |
| ---: | --- | --- | --- |
| 01 | `equipment-cabinet` | 设备柜体 | Equipment Cabinet |
| 02 | `central-control` | 中控系统 | Central Control System |
| 03 | `touch-control` | 触控系统 | Touch Control System |
| 04 | `curtain` | 遮阳系统 | Shading System |
| 05 | `hvac` | 暖通系统 | HVAC System |
| 06 | `cable` | 线材 | Cabling |
| 07 | `intercom` | 可视对讲系统 | Visual Intercom System |
| 08 | `network` | 网络系统 | Network System |
| 09 | `surveillance` | 监控系统 | Surveillance System |
| 10 | `music` | 背景音乐 | Background Music |
| 11 | `lighting-control` | 灯控 | Lighting Control |

旧产品缺少 `所属系统` 时统一进入 `uncategorized`（未分类）。系统不会根据产品名称猜分类。可在产品库中多选后批量设置所属系统。

报价目录按以上固定顺序显示；默认隐藏没有报价产品的系统并自动补位序号。历史产品库目录 `电动窗帘系统`、`暖通管理系统`、`背景音乐系统` 和 `灯控系统` 保留原路径，不因报价显示名称调整而迁移产品笔记。

施工调试费保存在独立表 `quotation_construction_fees`，五个固定项目以分保存。非零项目追加到报价明细最后，并在目录和汇总各显示一项；费用计入总额但不参与系统折扣和税额。v3.2 旧报价读取时五项默认 0。

## 知识库产品字段

产品 Markdown frontmatter 增加：

```yaml
所属系统: lighting-control
```

产品仍保存在知识库 `01_产品库`，图片仍保存在 `09_附件/产品图片`。数据库只保存兼容关联和项目报价快照。

## Excel / CSV 产品导入

必填列：

- 品牌
- 产品名称
- 分类
- 售价（或标准价格）

推荐列：

- 型号
- 点位类型
- 所属系统（填写上表中的英文 ID）
- 进货价
- 产地
- 单位
- 参数
- 说明

## 数据库迁移

现有 `quotes` 表增加报价版本、项目快照、显示设置、税率、折扣、模板、公司信息、日期和 Logo 字段。

新增：

- `quotation_systems`：每个报价的系统和服务费设置。
- `quotation_items`：点位合并项、旧直接加项和 V2 临时报价项。
- `quotation_versions`：不可覆盖的历史版本快照。

旧 `quote_lines`、`manual_quote_lines` 和点位产品快照保留。首次进入 V2 报价时按产品 ID 与项目单价同步；同产品同单价自动合并数量。手动改数量后设置 `quantity_override`，不会再被图纸数量覆盖，用户可点击恢复图纸数量。

## PDF

PDF 由 Playwright Chromium 打开 `/print/quotation/{projectId}` 打印生成：

1. 等待报价数据完成；
2. 等待 `document.fonts.ready`；
3. 等待全部产品图片完成；
4. 使用同一 DOM 和打印 CSS 输出 320 × 180 mm 横版 PDF。

字体由 `@fontsource-variable/noto-sans-sc` 随前端打包，中文、英文和金额保留为可搜索的矢量文字。

# RQ-017B 本地 data 工作库核验

日期：2026-10-02。状态：后端读写切换及 Mac 临时副本验证通过；正式 Windows Portable 包尚未发布，实机验收未完成。

## 数据来源与目录

组装 Portable 包时，以当前 NAS 知识库为数据来源，复制 `01_产品库/`、`06_客户档案/智能图纸与报价/`、`09_附件/` 等现有知识库目录到包内 `data/`，另复制本工具现有 `data/uploads/` 中的原始图纸和背景图。不要把旧工具的 `app.sqlite3` 当作主数据复制；它只是可重建的缓存。RQ-017C 已加入只创建新包的组包工具；Windows runtime 的完整性检查和现场验收仍未完成，不要用未验证的包覆盖用户已有 `data/`。

后端 Portable 模式只使用当前包的 `data/`：产品笔记在 `01_产品库/`，品牌笔记在 `01_产品库/_品牌/`，项目/点位/报价在 `06_客户档案/智能图纸与报价/`，产品图片与 Logo 在 `09_附件/`，图纸原件和背景图在 `uploads/`。SQLite 缓存、导出和日志也写在包内 `data/`。启动时发现这些必要目录缺失会明确报错；不会静默生成一份空知识库。旧环境变量指定的 NAS/本机目录与旧 SQLite 导入入口在 Portable 模式下不参与业务数据读取。

## 验证

- 自动化测试在临时包中创建项目、品牌、产品、Logo、产品图、图纸和报价；删除包内 SQLite、移动整个包后，重新从 Markdown 与附件恢复，读取和再次保存均通过。旧机器 SQLite 中的产品未被导入，错误的路径环境变量未生成目录。缺少 `data/` 的包拒绝启动。
- 使用当前知识库的**临时只读来源副本**启动：重建得到 3 个项目、16 个有效产品、14 个品牌；项目详情、报价、现有图纸均可读取。正式 NAS 文件未改动。
- 后端全套回归：34 通过、3 失败。失败为现有异步知识库同步时序断言（RQ-017-HD、RQ-012、RQ-013），本阶段未改其机制。Windows 断 NAS、移动盘符、真实启动与导出仍待 G 阶段验收。

## 后续

RQ-017C 需实际组装并启动包含 `app/`、`runtime/`、`data/`、`config/`、`backups/` 和 `version.json` 的完整包，确保替换程序时不碰 `data/`。现有固定 `%LOCALAPPDATA%` 的脚本仍是早期入口，不能视为本阶段的正式交付。

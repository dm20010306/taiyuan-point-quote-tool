# 设备点位图标规范

![[../frontend/public/icon-spec.svg]]

## 设计规则

- 使用 48 × 48 统一坐标网格。
- 使用白色底、单色描边，线端与转角统一。
- 智能开关沿用参考图中的红色面板和四键结构。
- 人体传感器沿用绿色同心圆结构。
- 窗帘沿用蓝色电机盒结构；图纸上的实际窗帘仍使用带双向箭头的线段表示长度。
- 图标几何中心即点位坐标，文字标签单独放在图标右侧，不参与落点中心计算。

## 设备与默认颜色

| 设备类型 | 符号特征 | 默认颜色 |
|---|---|---|
| 智能开关 | 方形面板、四个按键 | `#e51f4b` |
| 窗帘 | 长方形电机盒、两端驱动轮 | `#2459b8` |
| 人体传感器 | 双同心圆、中心探测点 | `#079447` |
| 温控器 | 方形面板、温度计 | `#e59144` |
| 调光 | 圆形灯光、四向光线 | `#d39a16` |
| 智能门禁 | 门框、读卡面板 | `#555e75` |
| 摄像头 | 机身、镜头、拍摄方向 | `#dd5360` |
| 网络设备 | 路由器、无线波纹 | `#2c9bce` |
| 水浸传感器 | 圆形探测器、水滴 | `#008fb3` |
| 影音设备 | 音箱、双单元 | `#ad6c9e` |
| 智能系统 | 控制模块、上下功能区 | `#293f71` |
| 其他设备 | 六边形通用设备标记 | `#737b8c` |

# Project instructions

Before changing this project, read `docs/REQUIREMENTS.md`, `docs/ISSUES.md`, `docs/CHANGELOG.md`, and `docs/DEVELOPMENT_RULES.md`.

Follow the active RQ or ISSUE scope and the durable rules in `docs/DEVELOPMENT_RULES.md`. Record implementation, tests, limitations, and status in the three project documents and the relevant help content. Never mark an untested Windows migration or release as resolved.
